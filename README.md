# Career Launch Pack

AI-powered career document generator. Customers paste a job posting + their background, pay $17, and receive a tailored resume, cover letter, and LinkedIn About section via email — generated by a 4-agent Claude pipeline.

## How it works

1. Customer fills out the order form on the storefront
2. Stripe Checkout handles payment
3. On successful payment, the webhook triggers the 4-agent Claude pipeline:
   - **Researcher** — extracts keywords and requirements from the job posting
   - **Writer** — drafts all three documents
   - **ATS Optimizer** — improves keyword coverage
   - **Editor** — final polish pass
4. Resend emails the completed pack to the customer

## Setup

### 1. Install dependencies

```bash
npm install
```

### 2. Add environment variables

```bash
cp .env.example .env.local
```

Fill in your keys (see `.env.example` for details):
- **Anthropic API key** — console.anthropic.com
- **Stripe secret key + webhook secret** — dashboard.stripe.com/apikeys
- **Resend API key** — resend.com (free tier works)

### 3. Run locally

```bash
npm run dev
```

### 4. Test Stripe webhooks locally

Install the Stripe CLI, then:

```bash
stripe listen --forward-to localhost:3000/api/webhook
```

Copy the webhook signing secret into `STRIPE_WEBHOOK_SECRET` in `.env.local`.

### 5. Deploy to Vercel

1. Push this repo to GitHub
2. Go to vercel.com → New Project → import the repo
3. Add all env vars from `.env.example` in the Vercel dashboard
4. Set `NEXT_PUBLIC_BASE_URL` to your Vercel deployment URL
5. In Stripe Dashboard → Webhooks → Add endpoint: `https://your-app.vercel.app/api/webhook`

## Pricing

Default price is **$17 USD**. To change it, edit `unit_amount` in `app/api/checkout/route.ts` (Stripe uses cents, so 1700 = $17.00).
